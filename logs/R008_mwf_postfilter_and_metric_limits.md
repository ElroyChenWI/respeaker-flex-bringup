# R008 — MVDR + Wiener 後處理濾波（MWF），以及能量 SNR 指標的極限

- 日期：2026-10-10
- 錄音：同 R007（`doa_20261010_182453_truebeam.wav`；講話 1.0–13.5 s，只有音樂 14.3–19.5 s；干擾約 196°，講話者 90°）

## Hypothesis

在 MVDR 後面加單聲道 Wiener 後處理濾波（decision-directed 的先驗 SNR，增益下限 −15 dB），組成 MWF，就能把「空間濾波 + 頻譜降噪」結合起來，接近或超過 XVF ch1。

## 動作

1. `beamformer.py`：
   - `output_noise_psd(Rn, w) = wᴴRn w`
   - `wiener_postfilter(Y, λ, α=0.98, floor=−15 dB)`
2. 合成測試：開關式的目標 + 很強的不相關噪音，噪音 PSD 用另一段獨立的片段來學 → SNR **+9.0 → +14.5 dB**，目標能量保留 −0.9 dB。通過
3. **修正評估方法的漏洞**：原本 MVDR 用「只有噪音」的那段算共變異矩陣，評分時又用同一段量殘留噪音，等於拿訓練資料評分
   - 改成前半段（14.3–16.9 s）算統計量，後半段（16.9–19.5 s）評分
4. `beam_eval.py` 新增兩個輸出：「mic0 + Wiener」（只有頻譜濾波，用來對照）和「MVDR + Wiener（MWF）」

## 觀察

**train/test 分開之後**（目標 90°）

| 輸出 | 推估 SNR | 比 mic0 |
|---|---|---|
| mic0 | 6.6 dB | 0 |
| mic0 + Wiener | 20.1 dB | +13.5 |
| delay-and-sum | 6.8 dB | +0.2 |
| MVDR | 12.0 dB | **+5.4**（分開評分後反而從 +4.9 升到 +5.4） |
| MVDR + Wiener | 26.6 dB | +20.0 |
| XVF ch1 | 21.4 dB | +14.8 |
| XVF ch2 | 7.9 dB | +1.3 |

**質疑這個指標：改變增益下限，看分數怎麼變**

| 變體 | 「SNR 提升」 | 講話功率保留 | 噪音（測試段）變化 |
|---|---|---|---|
| MVDR | +5.4 | −1.5 dB | −6.9 dB |
| MWF 下限 −6 dB | +11.1 | −1.8 | −12.8 |
| MWF 下限 −10 dB | +15.0 | −1.8 | −16.8 |
| MWF 下限 −15 dB | +20.0 | −1.9 | −21.9 |
| MWF 下限 −20 dB | +24.9 | −1.9 | −26.8 |
| MWF 下限 −25 dB | +29.3 | −1.9 | −31.2 |

- 「SNR 提升」幾乎 1:1 跟著增益下限走 → **對有非線性後處理的系統，這個指標可以被操控**
- 「講話功率保留」是用 (P混合 − P噪音) 推估的，裡面還混著講話期間殘留的音樂，只能當參考

## 結論

- MWF 本身有效：只有音樂的時段，噪音被壓了約 22 dB，講話功率大約只降 2 dB
- MVDR 的 +5.4 dB 是線性空間濾波的結果，**這個數字可信**
- **不能拿這個指標宣稱 MWF 比 XVF ch1 好**：兩者都有非線性的頻譜降噪，XVF 還有 AGC，分數主要反映壓制的深度，不是品質
- 公平比較需要的流程（下一步）：
  1. 在同樣的位置，分別錄「只有講話」和「只有音樂」的 6ch 音訊
  2. 在數位端相加成混合訊號（聲音在空氣中是線性疊加）
  3. **Shadow filtering**：在混合訊號上算出的增益，原封不動套到講話和音樂兩個成分上 → 得到真正的 SNR、講話失真（SDR）和 STOI
  4. XVF 是黑盒子，沒辦法 shadow filtering → 用盲測（ABX）或非侵入式的品質分數比較
- 預設增益下限維持 −15 dB；這個值應該依聽感和 STOI 來決定，不是依 SNR 分數
